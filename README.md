## 👩🏻‍💻 Sobre mim

Sou estudante do **2º semestre de Análise e Desenvolvimento de Sistemas na Universidade Cidade de São Paulo (UNICID)**.

Estou construindo minha trajetória na tecnologia com projetos acadêmicos, estudos e muita curiosidade. Tenho explorado **desenvolvimento web, lógica de programação, banco de dados e segurança da informação**.

Gosto de aprender na prática, trabalhar em equipe e descobrir como a tecnologia pode ajudar a resolver problemas. Atualmente, tenho interesse especial em **Cibersegurança**, enquanto continuo conhecendo **Desenvolvimento de Software e Inteligência Artificial**.

## 🎯 Áreas que estou explorando

- 🌐 **Desenvolvimento web:** HTML, CSS, JavaScript e interfaces responsivas
- 🧩 **Lógica de programação:** algoritmos e resolução de problemas
- 🗃️ **Banco de dados:** SQL, modelagem de dados e documentação
- 🔐 **Cibersegurança:** fundamentos, proteção de dados e boas práticas
- 🤖 **Inteligência Artificial:** uso responsável de ferramentas e aplicações práticas
